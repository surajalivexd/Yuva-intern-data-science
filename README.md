# Customer Churn Prediction - Machine Learning Project

## Week 3 Internship Task

This project is part of my Week 3 Data Science internship task. The main objective of this project is to develop and evaluate a machine learning model using Python.

The project focuses on **Customer Churn Prediction**. Customer churn means that a customer stops using a company's product or service. A machine learning model can help identify customers who may be likely to leave so that the company can take action earlier.

## Project Objective

The main objectives of this project are:

- Prepare customer data for machine learning.
- Handle missing values.
- Encode categorical variables.
- Scale numerical features.
- Split the data into training and testing sets.
- Train different machine learning models.
- Compare model performance.
- Use cross-validation.
- Perform hyperparameter tuning.
- Evaluate the final model.
- Save the trained model for future use.

## Dataset

No real dataset was provided for this internship task.

Therefore, the Python program creates a sample customer churn dataset containing features such as:

- Age
- Tenure
- Monthly charges
- Total usage hours
- Support calls
- Payment delays
- Contract type
- Internet service
- Payment method
- Churn
